## 📌 Descripción del Proyecto
Este repositorio contiene un Análisis Exploratorio de Datos (EDA) profundo sobre una base de datos de una empresa de telecomunicaciones. El objetivo principal es identificar los factores demográficos, financieros y de servicio que impulsan la **evasión de clientes (Churn)**, proporcionando insights estratégicos para mejorar las tasas de retención.

## 🚀 Hallazgos Principales (Highlights)
Tras procesar la información y generar visualizaciones clave, descubrimos que:
1. **El peligro de los primeros meses:** La inmensa mayoría de las cancelaciones ocurren durante los primeros meses de servicio. Los clientes que superan el primer año desarrollan una fuerte lealtad.
2. **Contratos volátiles:** El contrato de pago "Mes a Mes" es el principal factor de fuga. Fomentar la transición a contratos anuales es vital para la compañía.
3. **Sensibilidad al precio:** Los usuarios en los rangos de cobro mensual más altos (Premium) presentan una tasa de abandono significativamente mayor, lo que sugiere una posible desconexión entre el precio pagado y el valor percibido.
